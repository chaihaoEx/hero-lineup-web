# 10. 分阶段实施路线

## 阶段 0：建立独立项目

状态：已完成（2026-07-31）

任务：

- 初始化 React、TypeScript 和 Vite。
- 建立 ESLint、Vitest 和 Playwright。
- 复制现有 UI、CSS、类型和纯 TypeScript 模块。

- `npm ci` 成功。
- `npm run dev` 能打开页面。

## 建议里程碑

| 里程碑 | 包含阶段 | 可交付结果 |
|---|---|---|
| M1 静态预览 | 0–1 | 完整 UI 和静态数据可浏览 |
| M2 本地工作区 | 2–3 | 保存、导入导出和备份可用 |
| M3 精确配装 | 4–5 | 英雄和勇士计算一致 |
| M4 完整产品 | 6–7 | 模拟和断网能力完成 |
| M5 正式上线 | 8–9 | 独立部署并停止依赖旧项目 |

## 执行原则

- 每次只推进一个可验收阶段。
- 每次迁移先建立测试，再替换旧逻辑。
- 不以固定演示数据临时冒充完成。
- 不因新项目重构而降低 UI 还原度。
- 未通过一致性测试前不删除旧 Rust 基准。
