# 07. UI 与交互迁移

## 1. 目标

复用现有 React 和 CSS，保持当前桌面版已经还原的页面布局与交互，不因移除 Tauri 而重新设计产品。

## 2. 可直接迁移

- 主页面和导航。
- 英雄列表和排序。
- 勇士列表。
- 英雄配装弹窗。
- 勇士配装弹窗。
- 装备、技能和附魔选择弹窗。
- 任务分组、任务卡片和成员选择。
- 装备需求统计。
- 模拟结果详情。
- PNG 导出视图。
- 字体和颜色样式。

迁移时先原样复制，再修正平台依赖，避免同时进行大规模视觉重构。

## 3. 需要替换的交互

| 桌面能力 | Web 替代 |
|---|---|
| Tauri 文件打开 | File Input |
| Tauri 文件保存 | Blob 下载 |
| Tauri asset URL | 静态 content URL |
| Tauri event | Worker message |
| SQLite 保存 | IndexedDB |
| 桌面数据包安装 | 静态内容版本更新 |

## 4. 浏览器适配

必须检查：

- Chrome、Edge、Safari、Firefox。
- 1280×720、1440×900 和更大屏幕。
- 系统缩放 100%、125%、150%。
- macOS 和 Windows 字体差异。
- 原生滚动条差异。
- 浏览器缩放。
- 弹窗高度和内部滚动。

第一阶段仍以桌面浏览器为主，不要求移动端完整适配。

## 5. 性能

- 大型装备列表使用稳定 key。
- 目录索引使用 `useMemo` 或模块缓存。
- 输入变化避免触发全部页面重渲染。
- 属性计算只计算当前编辑对象。
- 搜索输入可按需防抖。
- 图片使用浏览器懒加载。
- 模拟只能在 Worker 中运行。

## 6. 可访问性

弹窗和控件需要保留：

- `role="dialog"`。
- `aria-modal`。
- 可见焦点。
- Escape 关闭。
- 键盘选择。
- Switch 的 `aria-checked`。
- 图片替代文本。

## 7. 视觉回归

对关键页面保存基准截图：

- 主页面。
- 英雄配装。
- 勇士配装。
- 装备选择。
- 技能选择。
- 附魔选择。
- 冒险任务。
- 模拟结果。

Playwright 截图需要固定：

- 浏览器版本。
- viewport。
- 字体。
- 测试数据。
- 动画状态。

## 8. 验收条件

- 主要界面与迁移前截图没有明显退化。
- 英雄和勇士的完整用户流程可用。
- 弹窗和列表不出现布局溢出。
- 装备或技能变化立即刷新属性。
- 浏览器刷新不会丢失已保存体系。
- 所有桌面专用按钮均有 Web 等价行为或明确替代提示。
